Each project here is reconstructed from the files Pocketto leaves in a real repository: specs under `docs/pocket/spec/`, execution logs (`log.json`), per-task review reports, and `closeout.md`. Numbers come from those files. Where a plan is still open, the page says so.

Private projects are anonymized: client names, internal feature names, and commit SHAs are removed. Open-source projects are named and linked so you can check the code yourself.
