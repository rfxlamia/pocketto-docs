Getting started with Pocketto takes two steps: install it in your coding agent, then pick the workflow that matches the task in front of you. There is no server to run, no account to create, and no GitHub requirement. Everything in Core works locally.

## What you need

- **Node.js ≥ 18**: the `pocketto-pi` CLI runs on it.
- **One of the two supported hosts:**
  - [Claude Code](https://docs.claude.com/en/docs/claude-code) with the Pocketto plugin, or
  - [Pi](https://github.com/badlogic/pi-mono) with the `pocketto-pi` package (plus its [required extensions](/docs/getting-started/pi-setup)).

## The three layers

| Layer | What you get | Requirements |
|---|---|---|
| **Core** | The six-stage pipeline, nine standalone skills, the lifecycle CLI. Local-first. | None: no remote, no credentials |
| **[Enterprise](/docs/core-enterprise)** | GitHub synchronization for teams: issue reconciliation, phase PRs, tasklists. | A matching Core install + explicit opt-in |
| **[Education](/docs/skills/pocket-education)** | Mentor mode: you write the code, the agent teaches and reviews. | An opt-in during [pocket-init](/docs/skills/pocket-init) |
